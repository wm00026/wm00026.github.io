# My Experience with Learning Rust (so far)

***Date: 23 July 2026***

I've recently began trying to learn Rust, one of the "systems languages" that has become increasingly more popular over time. Along with some basic working knowledge of the **C Programming language**, I wanted to learn Rust for a few reasons.

1. Rust is "generally" more safe on memory than C, due to the virtue of Ownership compared to general memory allocation that C uses. So Rust doesn't have as many issues with buffer overflow and other memory issues that C has. 
    - That doesn't mean C is inherently worse than Rust. That would be insane for someone to say. But Rust just has the advantage of better technology and more recent time.
2. Rust feels like one of those languages a cybersecurity focused person *should* be at least knowledgable in. Languages like Python, Bash, Powershell, and C also fit into this category. 
    - Again, technically Bash and Powershell aren not a language, it's a "command interpreter" and command language, different from Python or Rust or Java.
3. Rust seems like something "fun" to learn, as its outside of my general workflow of Java. 

So, I'd like to discuss what's it's been like to learn Rust so far, as well as discuss how I want to go about continuing learning not only Rust, but other subjects in general.

## Resources
There are a few good resources that I have found to learn Rust. Like learning most programming languages, there's a variety of sources that one can. I've mainly focused on books and manuals.

- *"The Rust Programming Language"*, by Steve Klabnik, Carol Nichols, and Chris Krycho. Also known as *The Book*, it is the main resource I have used to learn Rust. It has many recommendations from "Rustians" and has a good depth of knowledge. It's also incredibly accessible, with the book published online for free [linked here](https://doc.rust-lang.org/stable/book/index.html)

- "Rust101" by "ralfj". It's a hands-on course that is small, based on writing actual code. It's a great supplemental item along with the book, imo. It's available here: [Rust-101](https://www.ralfj.de/projects/rust-101/main.html)

These are the main resources that I've looked into so far. I'm sure there are plenty more resources online.

## Methodology
### Note Taking
My methodology for learning Rust is something that I've wanted to focus on the most. I have always struggled with taken dedicated notes on really anything, it's one of my studying weaknesses. With this learning experience, I'm trying to improve my note taking abilities and structure. 

To take notes, I've been using Obsidian. It's a note taking and "personal knowledge base" software that uses markdown files. It's similar to software like Notion, but it's open source. I've mainly wanted to focus on structuring my notes, actually learning how to take notes rather than just copy down the words from The Book.

<img src="/pictures/obsidian-screenshot.png" width="750" alt="Picture of my Rust notes in Obsidian">

*A picture of my Obsidian notes page.*

So far, it's worked out alright. Note taking is pretty easy with Obsidian and Markdown, so it's mostly just trying to understand the material.

### Making Tangable Programs
This part is a work in progres, so there isn't much to add here. After I am familiar enough with the basics of Rust, I want to build tangable programs. Mainly on actually useful programs that do the work that they are designed to do. Again, finding ideas for what programs to build and beginning building is a struggle point, so I will want to focus on that. The *Official Rust Documentation* will be helpful here. [The Standard Library Documentation](https://doc.rust-lang.org/stable/std/index.html) **or** [The Rust Reference](https://doc.rust-lang.org/stable/reference/introduction.html)

Using these materials, I hope that the program building progress will be as "simple" as possible.
